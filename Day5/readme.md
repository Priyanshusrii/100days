## Overview
A command-line Rock-Paper-Scissors game where the user competes against the computer across multiple rounds, with scores tracked until the player decides to quit.

## Features
- Play Rock, Paper, or Scissors against a computer opponent
- Computer makes a random choice each round
- Round-by-round result display (win/lose/tie)
- Running score tracker across the session
- Option to keep playing or exit anytime
- Input validation for invalid choices

## Concepts Used
- Python `random` module
- Conditional statements and game logic
- Loops for repeated rounds
- Functions for modular code
