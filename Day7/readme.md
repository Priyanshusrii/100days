## Overview
A command-line dice rolling simulator that lets users roll one or more dice at once, view individual results, and see the combined total — with the option to keep rolling.

## Features
- Roll any number of dice in a single go
- Random result generation for each die (1–6)
- Displays individual roll outcomes and the total sum
- Option to roll again without restarting the program
- Input validation for the number of dice

## Concepts Used
- Python `random` module
- Loops and functions
- Lists for storing multiple roll results
- Basic string formatting for output display

## Sample Usage
```
How many times  you want to roll  or type 0 to exit? 3

Rolls: [4, 6, 1]
Total: 11

```
