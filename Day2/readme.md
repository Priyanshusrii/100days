## Overview
A command-line tool that evaluates the strength of a user-provided password based on common security criteria and provides feedback on how to improve it.

## Features
- Validates password length, case usage, digits, and special characters
- Assigns an overall strength rating (Weak / Medium / Strong)
- Displays specific feedback for each unmet requirement
- Checks against a list of commonly used weak passwords


## Concepts Used
- String manipulation
- Regular expressions (`re` module)
- Conditional logic and functions
- Basic input validation
