## Overview
A simple command-line game where the program randomly selects a number within a defined range, and the user tries to guess it. 

## Features
- Randomly generated target number within a specified range
- Tracks and displays the total number of attempts

## Concepts Used
- Python `random` module
- Basic input/output operations

## How to Run
1. Make sure Python 3.x is installed on your system.
2. Navigate to this folder in your terminal.
3. Run the script:
```bash
   python main.py
```
4. Follow the on-screen prompts to guess the number.
