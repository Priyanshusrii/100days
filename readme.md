# 100 Days of Python Projects 🐍

## Overview
This repository documents a personal challenge of building **one mini Python project every day for 100 days**. The goal is to strengthen problem-solving skills, explore different areas of Python (automation, APIs, GUIs, file handling, OOP, web scraping, data analysis, and more), and build a consistent, visible track record of hands-on coding practice.

Each day represents a new, self-contained project — small in scope but focused on applying and reinforcing core programming concepts through real, working code rather than just theory.

## Purpose
- Turn Python knowledge into practical, working applications
- Build consistency and discipline through daily coding practice
- Explore a wide range of Python libraries, tools, and problem domains
- Create a public, day-by-day record of growth and progress
- Develop the habit of writing clean, documented, and shareable code

## Repository Structure
Each day's work lives in its own folder, numbered sequentially:

```
📦 100-Days-of-Python-Projects
 ┣ 📂 Day-01
 ┃ ┣ 📜 main.py
 ┃ ┗ 📜 README.md
 ┣ 📂 Day-02
 ┃ ┣ 📜 main.py
 ┃ ┗ 📜 README.md
 ┣ 📂 Day-03
 ┃ ┗ ...
 ┗ 📜 README.md   (this file)
```

Every day's folder includes its own source code along with a short description of what that specific project does, the concepts it covers, and how to run it.

## Tech Stack
- **Language:** Python 3.x
- **Libraries/Tools:** Varies by project — may include `tkinter`, `requests`, `pandas`, `os`, `json`, `datetime`, `BeautifulSoup`, and other standard or third-party libraries depending on the day's challenge

## How to Use This Repository
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate into any day's folder:
   ```bash
   cd Day-XX
   ```
